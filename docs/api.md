# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 查询文档列表的参数说明

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `page` | 整数 | 否 | 页码，默认 1 |
| `size` | 整数 | 否 | 每页数量，默认 10 |
| `keyword` | 字符串 | 否 | 按标题关键字筛选 |

### 请求示例

```http
GET /api/docs?page=1&size=10&keyword=指南
```

## 查询单篇文档

- 请求方法：`GET`
- 请求路径：`/api/docs/{id}`
- 功能：根据文档编号返回单个文档条目。

### 返回示例

```json
{
  "id": 1,
  "title": "使用指南",
  "content": "本页记录本站的本地预览、构建检查和发布流程。",
  "updated_at": "2026-11-01"
}
```

## 错误码

| 状态码 | 含义 | 说明 |
| --- | --- | --- |
| 200 | 查询成功 | 正常返回数据 |
| 400 | 参数错误 | 页码或每页数量不合法 |
| 404 | 文档不存在 | 指定编号没有对应文档 |
| 500 | 服务异常 | 示例中不会真正发生 |
