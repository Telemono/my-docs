## 关于本站

我建立这个文档站，是为了完整练习从 Markdown 到公开网站的发布流程。本站内容使用 Markdown 编写，由 MkDocs Material 生成静态页面，再通过 GitHub Actions 自动部署到 GitHub Pages。这样修改文档后只需要推送源文件，不需要手工维护生成的 HTML。

## 实践目标

1. 使用 Markdown 和 MkDocs Material 编写四页文档。
2. 理解 `docs/`、`site/`、GitHub Actions 和 GitHub Pages 之间的关系。
3. 实现“推送文档 → 自动构建 → 自动部署 → 网页更新”。
4. 通过 Actions 日志和截图记录实践过程。
